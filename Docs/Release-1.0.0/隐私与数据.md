# 隐私与数据处理说明

以下描述 1.0.0（17）的实现，供使用与后续发布审核参考；并非对外部 API 服务数据政策的保证。

- API Key 分服务保存在 device-only Keychain，不写源码、翻译记录或截图。更新签名若改变身份或访问权限，可能读不到既有密钥。
- 快速与专业模式本机识字，只向用户配置的服务发送文字、语言、提示词与术语等翻译所需内容；不自动把 OCR 失败改为图片上传。
- 识图模式会上传重新编码的截图 / 图片及最多两张同图细节，可能带本机 OCR 文字参考；不复制原始 GPS、相机与拍摄时间元数据。图片依然可能包含用户自身的敏感画面，使用前应检查。
- 外部服务的日志、保留、地区与收费政策由所选账户和端点决定。Responses 请求设置 store=false，但这不等于所有服务均不保留数据。
- 本机历史保存文字结果，不保存截图，可搜索、删除和清空；关闭记录并保存时清空已有历史。
- 翻译缓存只在进程内存中保存，20 分钟有效、有条数和容量限制，不落盘、不存图片或识图解释；可关闭和清除。
- HTTP 会话不用持久 cookies 或 HTTP 缓存，不自动重试收费请求。当前没有 App 自建云端、广告或统计 SDK。
- HTML 文稿包含原文与译文，全部转义，无脚本和远程资源。使用系统分享或其他 App 打开文稿时，文件会进入用户选择的渠道。

测试 target 使用固定响应与虚构密钥，不进入 Release。合成测试图为虚构素材，真实菜单回归截图不含登录凭据或个人账号；测试图中的商标与内容仅用于识别回归，不表示关联或背书。

后续 TestFlight / App Store 发布需根据届时实际实现、第三方服务选择与数据处理范围重新核对隐私说明和平台申报。
