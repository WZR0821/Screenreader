# 使用读屏

## 第一次使用

1. 打开 **设置 → API 设置**，选服务商和模型，填写自己账户的 API Key，保存。默认配置为 DeepSeek / deepseek-flash；识图须选能接收图片的模型。可测试连接或获取模型，列表不可用时手动填写。
2. 打开 **设置 → 翻译**，选择来源、目标与默认模式。新安装默认“自动识别 → 英语”。
3. 回到翻译页，输入文字或点照片 / 文件导入图片，点击翻译。结果中可查看原文，也可在历史记录中再次打开。

API Key 只填在 App 内，不要放到截图、反馈或 GitHub。API 费用与可用模型由所选服务账户决定。

## 把操作按钮接好

### 1. 安装完整快捷指令

读屏 **设置 → 操作按钮 → 安装“读屏全文”**，在分享菜单选择“快捷指令”，点“添加快捷指令”并完成。分享菜单没有此项时先存到“文件”，再打开该 `.shortcut` 文件。

现有 **屏译全文** 可以继续使用；正常更新无需只因名称变化重新绑定。

### 2. 绑定长按

打开 iPhone 的 **设置 → 操作按钮**，滑动到 **快捷指令**，点击选择指令，选 **读屏全文**（已有旧绑定可选屏译全文）。必须选择整个快捷指令，单独的“翻译截图全文”动作不负责截屏和展示。

### 3. 实际试一次

解锁手机，打开待翻译页面，长按操作按钮。首次按提示允许所需权限。翻译完成后在全文窗口上下滑动；点“查看原文”展开或收起识别文字，点系统“× / 完成”关闭。

没有操作按钮时可从“快捷指令”App 运行同一指令。

## 手动创建时只需要三个动作

在快捷指令新建指令并命名“读屏全文”，按顺序添加：

```text
截屏
  ↓ 截屏图片
读屏 · 翻译截图全文
  ↓ 翻译文稿
快速查看
```

第二步的图片输入应选择第一步“截屏”的输出，第三步应选择第二步的翻译文稿输出，不要接回原始图片。完成后再到 iPhone 设置绑定操作按钮。

## 选择模式与提示词

快速适合普通文字，专业适合菜单、商品、通知和表格，识图适合照片、海报或 OCR 不确定的图片。可在翻译前切换；设置中还可开启“每次运行时选择模式”，操作按钮将询问本次模式，选择不覆盖默认偏好。

**设置 → 模式提示词** 分别编辑三种模式。可写“使用自然英语，保留价格和条件，不额外解释”。变量 `{target_language}` 会随目标语言变化；若自己固定写“译成英语”，切换其他目标语言前也应检查该要求。重置只清除当前选中的模式。

选择系统翻译服务后只有快速模式，实际系统翻译在 App 前台进行，首次可能需要下载语言。操作按钮仍使用已保存 API；系统失败不会自动切到收费 API。

## 显示、缓存与记录

**设置 → 外观与阅读** 可改颜色、字号、间距以及默认是否展开原文。系统文稿使用生成时的设置，改变后对下一次文稿生效。

**设置 → 缓存与记录** 可复用近期相同文字译文、清理缓存、选记录条数和清空记录。缓存只在内存中保存，App 或系统后台进程结束后可能消失；识图结果不复用缓存。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 只有短预览 | 用“翻译截图全文 → 快速查看”，不要选择隐藏兼容的旧截图预览动作 |
| 总是让我选图片 | 检查翻译动作输入是否连接“截屏”输出 |
| 找不到读屏动作 | 先打开一次 App；重签名改变 Bundle ID 时重新添加已安装 App 的动作 |
| 密钥或设置似乎丢了 | 更新签名需保持原应用身份及钥匙串访问权限；切换服务商会显示该服务自己的密钥 |
| 工具栏 / 关闭按钮暂时隐藏 | 尝试点空白处或滚到顶部；关闭控件属于系统 Quick Look，需记录 iOS 版本进一步排查 |
| 下方显示 WPS Office | 这是系统文稿推荐应用，不是读屏提供的翻译内容，本版无法控制 |
| 有字看不清 | 查看原文，必要时选择识图重试；模型也不应猜补不可辨认文字 |
| 识图被拒绝 | 检查实际模型是否支持图片；不要用仅支持文字的模型做视觉请求 |
| 提示内容不完整 | 接口长度截断、漏段或关键数字丢失将报错，不会自动发起重复收费请求 |

读屏不自动滚动原 App；要翻译屏幕之外的内容，需要提供新的截图或长截图。系统窗口高度不能在读屏中任意调整。
