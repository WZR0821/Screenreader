# 读屏 Screenreader 更新记录

> 这里是各版本的更新要点和验证记录，2026-11-18 从 README 移到本文件，文字保留原样（“日语注音”一节留在 README 的主要功能里）。功能介绍、下载和使用说明见 [项目首页](../README.md)。

## 1.3.3 截图默认出文字、快速模式提速与原图直译对位（构建 31）

- 截图翻译默认只出文字译文。“原图直译”改成开关，放在“翻译偏好 → 模式与识字”，默认关闭；打开后从下一次翻译截图开始生效，操作按钮的全文窗口也一样。已经出来的纯文字结果不会自己变，翻译页的主按钮会变回“翻译”，点一下就把同一张截图按原图直译重新翻译。
- 原图直译关着时，快速模式按纯文字发送，不再分块写 JSON，请求和回复都更短。专业模式照旧分块，用量不变。
- 识别截图文字的同时先和 AI 服务建好连接（只发不带密钥和内容的 HEAD 请求）；思考强度为“自动”时，快速模式把 Claude 5 系列调到 low，把 Gemini Flash 调到最低档。
- 原图直译按原文的行高、行数和对齐来排：字号不超过原文行高的 85%，译文逐行落在原文的行上，居中和靠右的单行保持原样；色块和文字颜色取自截图；提示词要求模型不把词挪到相邻的块里。

详见 [1.3.3 更新说明](Release-1.3.3/更新说明.md)。

## 1.3.2 AI 大模型、一屏主界面与间距调整（构建 30）

- 设置里的“API 设置”换成“AI 大模型”：最上面是“读屏正在用”的模型，下面按供应商列出，每家各自保存密钥、地址和模型。
- “添加供应商”不分国内外，Claude、ChatGPT、DeepSeek 排在最前，其后是通义千问、豆包、Kimi、智谱 GLM、MiniMax、Gemini；没有列出的服务用“自定义”添加，可以添加多个。
- 一个供应商下可以留多个模型，每个模型单独设置接口格式和思考强度；“换模型”在所有填了密钥的供应商之间一键切换，不用重填任何内容。
- 升级后原有的服务商、密钥和模型都保留，不需要重新设置。
- 翻译和设置两个主界面按屏幕高度排满一屏，不能上下拖动；屏幕放不下（小屏、大字号、横屏、键盘弹出）时照常滚动。
- AI 相关页面全部用系统分组列表样式。设置各子页的行高加大、图标放大，组与组之间和页面顶部的空白收窄；阅读页的短段落不再被核对图标撑高。

详见 [1.3.2 更新说明](Release-1.3.2/更新说明.md)。

## 1.3.1 设置交互与界面调整（构建 29）

- 翻译偏好、缓存与记录改为即选即生效，不再因为没点“保存”而悄悄丢掉改动。
- API 设置和模式提示词没有改动时“保存”不可点；有未保存的改动时，返回按钮换成“取消”，离开前会询问。
- 关闭翻译记录、调低保留条数、清空记录前都会确认，并写明要删多少条。
- 设置首页改为系统“设置”样式：彩色图标加右侧当前值；API 页的“模型”行和“选择模型”列表改用系统列表配色；译文核对改为与首行对齐的小图标；报错横幅更易读；圆角统一为连续圆角。
- 同时包含下面原定为 1.4.0 的长文、报错、思考强度和流式显示改进。

详见 [1.3.1 更新说明](Release-1.3.1/更新说明.md)。

## 长文与报错改进（原 1.4.0 测试包，构建 28，已并入 1.3.1）

- API 报错时同时显示服务商原话（如上下文过长、模型不存在），密钥和类似密钥的字符串会被遮住。
- 超过 4,000 字的文字分段并发翻译，最多同时 3 个请求，按原顺序拼回；版面块不拆开，逐组校验数字和表格。
- 目标为日语或中文时，也会拦下整段返回成另一种语言的译文。
- 设置中新增按服务商保存的“思考强度”（自动／关闭／低／中／高），“自动”与 1.3.0 完全一致。
- App 内阅读页边接收边显示译文，收完并通过校验后才替换为正式结果；快捷指令仍交付校验后的全文。

详见 [1.3.1 更新说明](Release-1.3.1/更新说明.md) 的后半部分。

## 1.3.0 原图直译（构建 27）

- 图片的快速、专业和 App 内系统翻译支持原位置覆盖译文，随时切换“阅读”。纯文字和识图说明继续使用阅读页。
- 支持原图对照、双指放大、点按段落核对；表格单元格、菜单名称和价格保留各自位置，竖排中日文保留列方向。
- 全文快捷指令同步支持原图直译、原图对照与完整译文核对，已有快捷指令无需重建。
- 日语注音沿用原有开关；字号和行距设置用于阅读模式，原图模式按区域适配，过长内容点开查看。
- 翻译记录仍只保存文字与位置。原图仅用于当前阅读和本次快捷指令结果，不写入翻译历史。

详见 [1.3.0 更新与验证说明](Release-1.3.0/更新说明.md)。

## 1.2.1 交互优化（构建 25）

- 主屏分别安排带文字的照片、拍照、粘贴入口和整行翻译按钮，语言区标明原文与目标语言。
- 点击翻译后直接进入阅读页查看当前步骤；返回主屏后任务继续，可查看进度或取消。完成时不打断正在查看的历史和其他页面；未修改原文时主按钮变为“查看译文”。
- 重新翻译保留旧译文，失败或取消时可继续阅读。主动重试跳过旧译文缓存，成功后更新缓存，保留识字复用。
- 核对弹窗提供固定在底部的“仅重译这一段／行”按钮；点按正文不再误开核对弹窗。历史、翻译信息与核对窗口统一关闭方式、圆角及拖动提示。
- 快捷指令全文窗口优先显示译文，原文放在文末展开，日语注音开关与正文对齐；翻译失败会中止快捷指令并说明原因，不再向后续操作返回空白结果。

详见 [构建 25 说明与验证范围](Release-1.2.1/界面与交互-构建25.md)。

## 1.2.1 界面优化（构建 24）

- 翻译页使用原生大标题与系统分组背景，语言、输入和照片／拍照／粘贴操作整合在同一面板。
- 翻译记录统一从“最近翻译 → 查看全部”进入，移除导航栏中重复的历史按钮；清空记录后主页同步更新。
- 注音开关只在日语译文标题旁显示；中文、英文和未生成译文时不显示。日语翻译记录详情同样适用。
- 输入框随文字调整高度；翻译按钮与导入工具位于输入区底部。翻译完成后进入独立阅读页，可点“编辑”返回原文。
- 译文在独立页面连续阅读，复制保留在标题旁；分享、重新翻译与模型/耗时信息收进“更多”菜单。阅读页使用连续背景，不保留输入面板或底部悬浮操作条。
- 设置页采用原生分组列表与分类图标，支持系统字号和深色模式；字号与排版统一从“设置 → 外观与阅读 → 译文显示”调整。
- 默认蓝色强调色与系统背景保持一致，保留已选主题和自定义颜色；复制后显示勾选反馈。

设计与验证范围见 [1.2.1 更新说明](Release-1.2.1/更新说明.md)。

## 1.2.0 更新

- 首次使用及缺失目标语言配置时默认译为中文，保留已保存的语言选择。
- 翻译页采用单行语言菜单，可直接选择原文语言、目标语言并交换；自动识别时禁用交换。
- 设置中的译文显示提供 12–30 pt 字号、0–20 pt 附加行间距、0–36 pt 段距，另可选择系统／衬线／圆角字体与加重正文。保留预设、一键恢复和原文展开选项，设置同步用于译文、表格、记录和全文窗口。
- 设置分为“翻译与阅读”“AI 配置”“数据与帮助”，本机语言包归入翻译引擎。
- 相同图片在相同识字条件下复用本机识字结果；只存文字与位置，最多 8 条／20 分钟。改变目标语言仍可复用；更换图片、原文语言、方向、模式、术语或过滤选项会重新识字。
- 本机批量翻译合并完全相同的段落请求，收到译文后还原所有出现位置、顺序和空行。关闭缓存或清除缓存同时作用于译文与识字。

说明与验证范围见 [1.2.0 更新说明](Release-1.2.0/更新说明.md)。

## 1.1.1 更新

- 根据 iPhone 上的真实网页测试修复日语正文被误判为列表、词语被换行拆开的问题。
- 改进静音图标与状态栏识别，合并紧邻的双语机构名称；优先复核异常日期与日文标题，并缩小标题复识别区域。
- 识图提示词强化目标语言、适用人群、遮挡边界与图片证据，减少原文重复；对英语结果中明显整段输出中日文的情况报错。
- DeepSeek 专业与识图采用明确的低强度推理，快速模式继续关闭推理；保持取消与不自动重试。
- 图片粘贴支持多种数据表示和临时文件回退，快捷指令失败显示可读的中文说明。

真机范围、失败样例和新版验证边界见 [1.1.1 测试与修复报告](Release-1.1.1/测试与修复报告.md)。

## 1.1.0 更新

- 隐藏内置模型指令预览，保留三种模式的自定义要求。
- 新增拍照，确认照片后立即翻译；文件入口替换为系统粘贴按钮，支持文字与图片。
- 新增竖排日语字形重排、文字方向选择、不确定文字的原图对照与逐项确认。

- 局部复识别按实际首轮耗时分配预算；清空缓存后，旧请求不会重新写回缓存。

## 各版验证记录

1.3.3 在同一台 iPhone 16 Pro（iOS 18.2）模拟器上跑了完整回归，发现 3 个应用问题，都已改好：打开原图直译后，已经翻好的截图看不到原图直译；快捷指令全文窗口的段落越往下越往上偏；全文窗口里的“…”比译文大（看截图时发现）。另有 3 项失败不是应用的问题：1 项测试还按旧的默认值，已改测试；2 项是网页进程和系统文字选择的偶发问题，原样重跑通过。最后的结果：核心检查 216 项、iOS 单元与集成测试 330 项全部通过；界面测试 78 项，第一轮通过 75 项，失败项所在的测试类和与改动有关的测试类改好后重跑，全部通过。其中新增核心检查 14 项、iOS 测试 8 项、界面测试 1 项。安装包是最后一轮测试通过后用同一份源码打的。没有上真机，提速没有用真实密钥计时。详见 [1.3.3 更新说明](Release-1.3.3/更新说明.md)。

1.3.2 在同一台 iPhone 16 Pro（iOS 18.2）模拟器上跑了两轮完整回归。第一轮有 1 项界面测试失败：键盘弹出时把翻译页滑上去再点“完成”，大标题没有恢复。这是应用的问题，改了 `OneScreenLayout.swift` 之后重跑整轮：核心检查 202 项、iOS 单元与集成测试 308 项、界面测试 77 项，全部通过。其中新增 `OneScreenUITests` 9 项、`OneScreenSizeTests` 5 项、`Release132UITests` 10 项、`ProviderStoreIntegrationTests` 6 项和核心检查 13 项。其他尺寸的手机没有对应的模拟器，只在测试进程里按尺寸排版核对过；没有上真机，新增的供应商也没有用真实密钥连过。详见 [1.3.2 更新说明](Release-1.3.2/更新说明.md)。

1.3.1 在一台 iPhone 16 Pro（iOS 18.2）模拟器上跑了新增的 6 项界面测试，以及 3 项涉及 API 页“模型”行的原有界面测试，全部通过，并逐张核对了截图。之后又跑了一轮完整回归：核心检查 189 项、iOS 单元与集成测试 284 项、界面测试 59 项。其中 3 项失败：2 项是测试过时，已修改测试；1 项是系统快捷指令搜索偶发没有返回结果。这 3 项重跑后都通过，应用代码没有改动。详见 [1.3.1 更新说明](Release-1.3.1/更新说明.md)。
