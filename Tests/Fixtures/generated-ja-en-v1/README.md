## 使用

在读屏翻译页通过“图片 → 文件”导入PNG。日英混排可选择“日语”或“自动识别”，英语邮件可选择“自动识别”；先译为中文，便于核对含义。测操作按钮时，可把原图保存到照片并全屏查看，再长按已有的“屏译全文”快捷指令。

- 快速模式：检查完整度、数字及否定条件，记录首次请求速度与重复请求缓存；不要求重建全部格式。
- 专业模式：检查标题、段落、选项、字段关系和最后一行。重点检查多列表格是否串列，不把价格或数量误删。
- 识图模式：检查文字大意与画面大意是否分开，关键金额和限制是否保留；照片、广告与插画只描述可见内容。不得猜人物身份、品牌真实性或看不清的文字。
- 全文窗口：字号和间距改变后，仍能滚到末段；原文可展开核对。系统窗口控件与真实硬件长按仍需真机测试。

比较模型时保持图片、语言、模式、提示词一致，记录服务和实际模型ID。缓存命中不用于比较首次API速度。`results-template.json`提供记录字段；填写时不要保存API Key。

## 参考边界

`manifest.json`包含每图的语言文本、布局意图、测试要点、尺寸和SHA-256；`prompts.json`保存实际使用的完整提示词。生成的文字可能与提示词存在空格、换行或额外标签差异，不能直接拿提示词计算逐字OCR准确率，必须以原图可见内容为准。

交通图的路线额外显示“青葉駅”“緑川駅”。咖啡店图还包含食物粉笔插画、室内吊灯和展示柜。海报还包含月亮、观众、湖面与帐篷。这些是图片真实可见元素，可用于检查看图结果，不能误记为App凭空生成。

本集为虚构开发素材，不是实际商品、交通、活动或预约信息。当前交付已将这些图片用于本机与 iOS 模拟器的真实 Vision OCR 回归；这不等于构建 17 的真机在线 API 翻译准确率验收。完整边界见仓库的 1.0.0 验证说明。后续应结合真实截图继续扩展测试集。
