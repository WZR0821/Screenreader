# 读屏 1.1.0（构建 18）

开发者署名：Jerry Wong。最低系统要求仍为 iOS 18，应用标识保持 `com.raydon.ScreenTranslate`。

## 本次更新

1. 设置中移除英文“预览模型指令”入口。内置翻译要求继续生效，快速、专业和识图的自定义提示词仍可分别编辑、保存和恢复默认。
2. 翻译页新增“拍照”。第一次使用请求相机权限；确认照片后立即开始当前模式的翻译。识图模式会上传重新编码的图片，快速和专业模式只上传识别文字。取消相机不会翻译或清空已有输入。没有相机或权限被拒绝时提供明确提示。
3. 原文件按钮替换为系统“粘贴”按钮。支持剪贴板中的文字或图片；识图模式只接受图片。粘贴文字会替换输入并移除旧图，粘贴图片会替换图片并清除旧识字。只在主动点击粘贴时读取内容，不读取复制链接指向的网络资源。
4. 新增竖排日语字形重排与方向选择。保留直立字形，把同一列的图像片段按上下顺序送入识字，再按从右到左输出列。原始区域坐标用于复核。横排模式可关闭此检测。
5. 小字、低置信度文字、可疑日语字形、日期、金额和竖排列入复核。点“复核”查看放大的原图区域、修改文字并逐项确认；只有已确认项会应用，其他提醒保留。手工确认允许修改金额，自动复识别仍保留数字保护。
6. 有明确表头和重复行的表格支持 3–8 列，保留空单元格和商品名称的续行。App 和全文文稿中的宽表格可横向滚动，表头和内容一起移动。
7. “设置 → 翻译 → 本机语言包”支持查看语言组合是否已安装、尚需下载或不支持，并通过 Apple 系统流程准备语言。返回 App 后刷新状态。
8. 本机翻译按段处理，按标识恢复原始顺序与段落分隔；显示完成段数。语言包安装后可离线使用，失败不会自动改用收费 API。
9. 缓存页显示条数、大小和本次运行命中次数。API 缓存与本机缓存隔离；本机缓存不再因修改 API 模型或提示词而失效。清空后，已在途的旧请求不能重新填充缓存。
10. 翻译期间显示当前阶段和阶段等待时间；结果可展开准备、识字、局部复核、翻译及总耗时。已在界面识别的文字直接复用，不把上一轮识字时间计入本次等待。局部复识别按首轮识字耗时安排有限时间预算，未完成的可疑项保留供人工复核。

## 安装与升级

安装包：`Screenreader-iOS-v1.1.0-build18-unsigned.ipa`。这是 iPhoneOS arm64 Release 未签名包，需使用自己的签名方式安装。沿用相同应用标识及签名身份覆盖安装可保留原设置；不要为了升级先删除旧 App。

设置底部署名为 Jerry Wong，版本为 1.1.0。已有“读屏全文”“屏译全文”快捷指令继续随包提供。重签名如更改了应用标识，应重新连接快捷指令的 App 动作。

## 使用边界与验收

- 竖排重排主要针对清晰、直立、列间可分的日语。弯曲文字、严重透视、艺术字、密集注音或复杂混排仍需要人工复核或识图模式；生成素材的识别通过不等于真实图片准确率保证。
- 相机实拍、首次相机权限、拒绝权限后的恢复、真实模型上传及语言包下载需要 iPhone 真机验收。模拟器可以验证无相机提示、剪贴板、原图复核和界面流程，不能证明真实拍照或离线语言模型的效果。
- 当前沿用 iOS 18 的 Apple 前台翻译接口。操作按钮继续使用已配置的 API。
- 缓存仍只在内存中保留，最多 40 项、约 1 MB、20 分钟有效；识图结果不缓存，重启 App 后清空。

本版验证结果、安装包校验和见同目录的验证报告。图片和语言包准备、OCR 与复核均在本机完成；识图上传与文字 API 的数据去向沿用用户选择的服务商。

## 实现依据

- [Apple LanguageAvailability](https://developer.apple.com/documentation/translation/languageavailability/status)：区分已安装、支持但未准备、不支持。
- [Apple prepareTranslation](https://developer.apple.com/documentation/translation/translationsession/preparetranslation())：语言准备由系统授权；自动来源没有文本时不能提前判定。
- [Apple Required Reason API](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons)：本机耗时测量声明 35F9.1，不传输系统启动时间。
