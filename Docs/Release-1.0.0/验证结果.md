## 重点验收

- 八张合成日英场景与真实菜单截图进行 Vision 识字回归，检查价格、数量、库存、条件、选项和末尾文本。
- 320 点宽、大字号 WebKit 渲染检查标题层级、段落、价格对应、列表、语义警告、编号、小数、日期及末段；没有横向溢出。
- 语义表情前不重复添加圆点；保留表情连接符、变体和肤色；孤立符号结合位置判断，真实数学关系与有意义数字保留。
- 中文界面、默认英语目标与 DeepSeek、交换语言、常规设置一屏展示、三个模式提示词分别保存 / 重置通过检查。
- 专业模式缺段、重复段、数字丢失 / 改写、串列或服务截断被拒绝；错误与取消不写成功缓存，不把迟到结果覆盖新输入。
- 系统全文指令可读到第 24 段及末尾；原文可展开 / 收起；关闭后再次运行成功，无需重启快捷指令。
- Release 不含测试 target、调试模拟入口、测试素材或真实 API 凭据；保留新旧全文指令以便兼容。

## 必须区分的边界

构建 17 未重新安装到真机执行在线 API 测试。协议和翻译管线使用固定响应验证，不代表模型的实际翻译准确率、在线视觉理解质量或真机延迟。Apple 系统翻译的下载、权限与实际输出仍需真机验收。

iOS 负责 Quick Look 工具栏和关闭按钮；用户反馈的偶发隐藏、WPS 推荐和窗口高度不是可由当前 HTML 修改的控制项。可滚动全文与再次运行已经在模拟器验证，不等于所有 iOS 版本均无系统问题。

合成图是测试素材，生成提示词不是逐字 OCR 黄金标注；应以真实像素为准。模糊艺术字、微小竖排和复杂版式仍可能无法完整识别。
