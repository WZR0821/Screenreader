# 界面优化 · 1.2.0（23）

## 页面结构

- 主页采用输入翻译、快速导入、最近记录三部分，统一背景、卡片、圆角和间距。使用最近记录继续阅读，或从照片、相机、剪贴板开始新翻译。
- 翻译按钮融入输入卡片；输入框随文字内容调整，长文字在输入区滚动。
- 翻译完成后进入独立阅读页，支持连续阅读和返回编辑原文。阅读页采用连续背景，不拉长内容框，也不保留底部悬浮翻译条。
- 字号、字体、行距与段距统一在“设置 → 外观与阅读 → 译文显示”调整。
- 注音仅出现在日语译文标题旁，中文、英文和主页不显示；翻译记录详情使用同样规则。
- 复制保留在译文旁；分享、重新翻译和模型/耗时信息集中在“更多”菜单。

## 交互与可访问性

- 阅读页直接观察当前译文与设置，字号和注音实时更新；开关不重新翻译。
- 支持超大系统字号下的纵向导入操作；阅读工具图标保持合适尺寸，正文继续跟随系统字号。
- 最近记录可直接进入详情并返回主页。相机、识字核对、局部重译、表格和全文内容继续保留。
- 本轮使用隔离测试数据和 iOS 18.2 模拟器验证。真机测试按此前要求继续暂停，未测试外部翻译服务。
