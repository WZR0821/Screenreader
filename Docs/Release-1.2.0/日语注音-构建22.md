# 日语假名注音 · 1.2.0（22）

## 使用

- 翻译页左上角点“注音”，立即开启或关闭；默认关闭，选择自动保存。
- 也可到“设置 → 外观与阅读 → 译文显示 → 日语假名注音”设置，并查看预览。
- 平假名居中显示在日语译文的对应汉字上方，字号为正文的 50%；词中的原有假名保留原位。
- 支持段落、列表、表格、翻译记录及核对译文页面。翻译记录详情也有快捷开关。
- 快捷指令全文窗口提供独立开关，初始状态跟随 App 设置，窗口内的临时切换不改动 App 设置。
- 在本机生成读音并缓存，切换不重新翻译、不增加 API 请求。复制、分享和历史存储仍使用纯译文。
- 读音来自系统词典；姓名、多音字和特殊读法需结合上下文核对，无法确定汉字与假名对应位置时不强行注音。
